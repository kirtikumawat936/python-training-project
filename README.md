# 🎓 Student Attendance Management System

A sleek, intuitive, and efficient desktop application built using **Python** and **Tkinter** designed to streamline tracking student daily attendance records. This tool simplifies database management, automates entry logging, and provides quick data exports for academic administration.

---

## 🚀 Key Features

* **👤 Student Management:** Easily add or remove student profiles from the active system database grid.
* **✅ One-Click Attendance Logging:** Dedicated controls to instantly mark a student as **Present** or **Absent** on the fly.
* **📊 Live Data Grid View:** Clear, clean table tracking student IDs, Names, and their real-time updated Attendance statuses.
* **📥 Instant CSV Export:** Export complete historical data spreadsheets with a single click for formal reporting in Microsoft Excel or Google Sheets.
* **🧹 Database Reset Utilities:** Clear the global record stack safely with integrated database wiping functions.

## 💻 How To Run the Project

Follow these steps to download and run this application locally on your computer:

### 1. Clone the Repository
```bash
git clone https://github.com
cd python-training-project
```

### 2. Launch the Application
Run the main graphical user interface file using python:
```bash
python gui_app.py
```
